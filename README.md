# 🚀 Meu Portfólio

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para centralizar minhas criações, demonstrar minhas habilidades técnicas e compartilhar minha evolução como desenvolvedor.

## 🛠️ Tecnologias Utilizadas

- **React** (com TypeScript)
- **Vite** (para um ambiente de desenvolvimento rápido)
- **JavaScript / TypeScript**
- **HTML5 & CSS3** (com foco em interfaces responsivas)

## 💻 Sobre o Projeto

Tenho foco na criação de aplicações web modernas, interfaces responsivas e soluções eficientes. Minha experiência envolve React, JavaScript, TypeScript e Node.

## Analytics

Para habilitar o Google Analytics 4, configure `VITE_GA_MEASUREMENT_ID` com o ID
real da propriedade (formato `G-...`) no ambiente de build. Sem um ID válido, o
script de analytics não é carregado. Consulte `/privacidade.html` para saber
mais sobre o formulário de contato e a medição de audiência.
